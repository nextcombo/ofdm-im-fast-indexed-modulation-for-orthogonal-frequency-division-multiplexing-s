# OFDM-IM: Fast Indexed Modulation for Orthogonal Frequency Division Multiplexing Simulations with MATLAB [Included MATLAB Code]

Fast-OFDM employs non-orthogonal basis functions (such as Discrete Cosine Transform - DCT), allowing subcarriers to be arranged more closely; In contrast, Index Modulation technology carries additional bit information by activating the index positions of subcarriers, not relying solely on the signal constellation diagram for data transmission.
Objective:
Simulate the Fast-OFDM-IM system in MATLAB environment
Conduct performance comparison analysis with traditional OFDM and OFDM-IM systems
Analyze key indicators such as Bit Error Rate (BER), Peak to Average Power Ratio (PAPR), and spectral efficiency
Support multiple modulation schemes (QPSK, 16-QAM, etc.)
Evaluate the performance under AWGN channel and Rayleigh fading channel
Features:
Use DCT/FFT to generate Fast-OFDM subcarriers
Full support for index modulation functionality
BER analysis under different SNR conditions
Frequency spectrum efficiency calculation function
Support for various channel models: AWGN, Rayleigh fading
Configurable modulation schemes: QPSK, 16-QAM, etc.
MATLAB simulation results
